# TugaFlix Stremio Addon

A static Stremio addon for TugaFlix with Portuguese subtitles.

## Features

- Watch TugaFlix movies and series in Stremio
- Portuguese subtitles (legendas PT)
- Works completely free via Netlify

## Installation in Stremio

1. Open Stremio
2. Go to "Add-ons" → "Add-ons from URL"
3. Enter: `https://tugaflix-stremio-static.netlify.app/manifest.json`
4. Click "Install"

## Content

### Movies
- The Wrong Girls (2026) - Available with Portuguese subtitles

### Series
- The Lowdown (2025) - Available with Portuguese subtitles

## Technical Details

- Static addon compatible with Stremio 4.0+
- CDN-delivered content
- Free hosting on Netlify
- Zero backend or database requirements
